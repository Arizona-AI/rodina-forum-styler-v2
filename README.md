Расширение для **Chrome (MV3)** и **Firefox 115+**, которое полностью переодевает
форум [Rodina RolePlay](https://forum.rodina-rp.com/): 229 готовых тем, свой
редактор палитр, фоны (картинки, GIF, видео, градиенты, рисованные сцены),
эффекты, шрифты, курсоры, стекло и 26 тумблеров тонкой настройки XenForo.

Вся панель управления живёт **в попапе расширения** — со сайдбаром и всеми
16 разделами. Отдельной вкладки настроек нет.

<details>
<summary><b>Почему «229 тем»</b></summary>

113 тем собраны из 16 концептов × 7 вариантов, ещё 116 — это перенос пресетов
**Arizona Forum Styler** (`tools/generate-arizona-themes.mjs` разбирает их
`popup.js`). Итого 229 тем в 9 категориях: тёмные, светлые, неон, пастель,
минимал, ретро, природа, фэнтези и Arizona.

</details>

## Возможности

| Раздел | Что внутри |
| --- | --- |
| **Обзор** | состояние расширения, текущая тема, статистика, быстрые стили («Стиль Arizona» / «Сбросить вид» — один клик меняет логотип, аватары, радиус, кнопки и акценты) |
| **Темы** | 229 пресетов, поиск, фильтры по категории и режиму, избранное, случайная тема, свои темы (до 100) с экспортом |
| **Редактор** | 30 токенов, живой предпросмотр макета форума, undo/redo на 50 шагов, проверка контраста по WCAG |
| **Внешний вид** | радиусы, форма кнопок, аватары, обводка/покрас в цвет ника, логотип (градиент/своё изображение), синхронизация светлой/тёмной вариации XenForo |
| **Фон** | цвет, градиент, картинка, GIF, видео, 5 рисованных SVG-сцен; затемнение, blur, размер, фиксация, автоплей и пауза скрытой вкладки |
| **Эффекты** | снег, частицы, туман на canvas, свечение, анимированный градиент; 13 стилей перехода появления страницы |
| **Шрифты** | Google Fonts-пресеты или свой `font-family`, вес, масштаб, трекинг, область применения |
| **Курсоры** | прицел, кольцо, точка, шеврон, свой URL; цвет из активной темы, размер 16–64 px |
| **Стекло** | glassmorphism с размытием — блоки, посты, навигация и меню по отдельности |
| **Интерфейс форума** | 26 тумблеров (футер, сайдбар, аватары, индикаторы непрочитанного, липкая шапка, баннеры…), акценты Arizona, оформление заблокированных, анимированные аватары, кнопка «Ссылка» на выделение, свои пункты меню шапки |
| **Производительность** | режимы полный/бережный/лёгкий, лимит FPS, авто-пауза canvas на скрытой вкладке |
| **Доступность** | `prefers-reduced-motion`, отключение переходов, кольцо фокуса, буст контраста |
| **AI** | локальная эвристика «без ИИ, офлайн» (генерация токенов, подбор палитры, план улучшений) + опциональный OpenAI-совместимый endpoint (HTTPS, явное согласие, ключ не экспортируется) |
| **Импорт / экспорт** | JSON-бандл, share-код base64url, drag&drop, режимы «объединить» и «заменить всё», миграции по версиям |
| **Экспериментальное / Расширенное** | миграции, сброс, отладочные сведения, диагностика шаблона форума |

Плюс **диагностика** (сверка шаблона XenForo с реальным DOM), **онбординг** с
выбором темы при первом запуске и **импорт/экспорт без потерь** — настройки
и свои темы переезжают между браузерами одной строкой.

## Установка

### Chrome / Edge / Brave (MV3)

```bash
npm install
npm run build          # собирает ./dist
```

1. Откройте `chrome://extensions`
2. Включите «Режим разработчика»
3. «Загрузить распакованное расширение» → выберите папку `dist/`

Распространяемый архив: `npm run package` → `rodina-forum-styler-v1.4.1.zip`.

### Firefox 115+ (MV3)

```bash
npm run build:firefox  # кладёт manifest.firefox.json как dist/manifest.json
```

1. Откройте `about:debugging#/runtime/this-firefox`
2. «Загрузить временное дополнение…» → `dist/manifest.json`

Firefox-манифест отличается только `background.scripts` вместо `service_worker`,
gecko-id и `strict_min_version: 115.0`; бандлы те же (цели сборки `chrome110` +
`firefox115`).

### Режим разработки

```bash
npm run dev            # --watch, sourcemaps, без минификации
```

Страница форума поднимается локально для проверки без реального форума:

```bash
node tools/serve.mjs   # http://localhost:8477/
```

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run build` | продакшен-сборка в `dist/` (минификация) |

| `npm run package` | `dist/` → версионный zip |

Служебные аудиты (Node, без дополнительных зависимостей):

```bash
node tools/audit-i18n.mjs     # каждый t("ключ") существует; EN = RU, плейсхолдеры
node tools/audit-imports.mjs  # нет неиспользуемых импортов
node tools/render-vars.mjs    # рендер скомпилированного CSS темы в файл
```

## Как это работает

Контент-скрипт внедряет два `<style>` — `#rfs-base` со статикой форума и
`#rfs-vars` со скомпилированными переменными темы — и атрибуты-флаги
`data-rfs-*` на `<html>`.

CSS реагирует только на атрибуты и переменные `--rfs-*`, а не трогает элементы
форума напрямую, поэтому:

* переключение настройки не ломается на обновлениях DOM XenForo;
* изменения приходят через `chrome.storage.onChanged` (событийная модель,
  без поллинга) и применяются во вкладках форума мгновенно;
* тема — набор из 30 декларативных токенов (26 цветов, 3 радиуса, стек
  шрифтов), ничего исполняемого, поэтому импорт и AI-генерация безопасны
  по построению.

Детали — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Разрешения и безопасность

Минимально возможный набор: `storage` + один host-паттерн форума.

* ключи и URL AI-провайдера хранятся отдельно и **никогда не попадают в экспорт**;
* весь CSS санитизируется, URL фонов и курсоров валидируются;
* локальная эвристика работает офлайн и никуда не отправляет данные;
* политика и модель угроз — в [docs/SECURITY.md](docs/SECURITY.md).

## Технологии

* **Vanilla TypeScript** в строгом режиме — без фреймворков и
  рантайм-зависимостей
* **esbuild** — сборка всего проекта за доли секунды
* **node:test** — 125 тестов без дополнительных тестовых фреймворков
* только браузерные API расширений: `chrome.storage`, `scripting`, `tabs`

Требования: **Node 20+**.
