# Changelog

## 1.4.1 (2026-10-11) — тёмно-красный стиль панели + недостающие виджеты

### Стиль панели: тёмно-красный (dark red)

* Новая палитра панели: глубокий бордовый фон (`#12080c`), алый акцент
  (`#e11d48` / `#ff4d6d`), тёплые тени с винным подтоном.
* Амбиент: мягкое красное свечение сверху и снизу (radial-gradient) в тёмной
  теме; светлая тема перекрашена в розово-винные тона.
* Сайдбар: вертикальный градиент + винное свечение у границы с контентом;
  активный пункт — градиентная подложка и светящийся багор слева.
* Бренд-марка, кнопки (градиент crimson → wine с inset-бликом), тумблеры
  (градиент + glow), слайдеры (трёхцветная заливка), карточки, статистика
  (числа — красный градиентный текст), заголовки групп, модалки, онбординг —
  перекрашены и утончены; тонированные скроллбары.

### Дописаны стили виджетов, которых никогда не было (~140 классов)

Панель тем, дашборд и встроенные панели (редактор, ИО, AI, диагностика,
онбординг) использовали классы без каких-либо CSS — в попапе (iframe на
`options.html`) они выглядели неоформленными. Теперь всё стилизовано в той же
тёмно-красной теме:

* **Темы**: поиск, фильтры-чипы (категории/режим/избранное), счётчик,
  сетка карточек (превью-градиент, бейдж «Моя тема», действия, активная
  карточка с алой рамкой), «Случайная тема», кнопка избранного ♥.
* **Дашборд**: баннер главного тумблера, статистика (4 карточки),
  текущая тема (превью + чипсы), быстрые стили Arizona, быстрые действия,
  статус форума, футер с версией.
* **Редактор тем**: тулбар (имя/описание/undo-redo/live-preview), колонки,
  группы токенов, форум-макет (шапка/пост/сайдбар на CSS-переменных темы),
  контраст-метр, предупреждения, действия.
* **Импорт/экспорт**: режимы (merge/replace), drop-зона, поле кода.
* **AI**: карточки генератора/ассистента/проверки, свотчи, удалённый API.
* **Диагностика**: списки модулей/селекторов (чередующиеся строки, mono-id),
  сбросы, статус форума.
* **Онбординг**: плитки тем, свитчи, шаги.
* `.btn-sm`, `.card-actions`, `.card-note`, `.rfs-section-footer/panel/titles`.

### Версия

* 1.4.1: только стили (`options.css`) — поведение и контракты не менялись.

## 1.4.0 (2026-10-11) — вся панель переехала в попап

### Меню расширения — только в попапе

* Попап теперь — **полная панель управления** (все 16 разделов с сайдбаром,
  как на скриншоте): `popup.html` — тонкая оболочка с iframe на
  `options.html?popup=1`. Все функции (темы, редактор, фоны, эффекты, шрифты,
  курсоры, стекло, интерфейс форума, производительность, доступность, AI,
  импорт/экспорт, экспериментальное, расширенное) — там и больше нигде.
* Отдельная вкладка настроек убрана: `options_ui` удалён из обоих манифестов,
  первичный вход — только иконка расширения. Онбординг запускается при первом
  открытии попапа (service worker больше не открывает options-страницу).
* Режим popup: `options.ts` помечает `<html data-popup>`, CSS панели в этом
  режиме держит сайдбар развёрнутым (без бургер-меню) при ширине попапа 800px.
* Удалены мёртвые ключи i18n старого табового попапа (222 → 204) и
  `openDashboard`/`openOptionsPage` из `shared/browser.ts`.
* popup.js больше не собирается — попапу нужен только HTML+CSS.

## 1.3.0 (2026-10-11) — попап с вкладками + фикс смены тем

### Критический фикс: темы наконец-то переключаются

* `theme.activeId` не имел схемного контрола и **терялся при каждой
  валидации** (`validateSettings` строит результат из дефолтов и копирует
  только схемные поля) — активная тема молча сбрасывалась на Rodina Eclipse
  при каждом сохранении/загрузке. Теперь id сохраняется с санитизацией
  slug-формата; регрессионный тест в `settings.test.ts`.
* Итог: выбор темы в попапе, панели и через импорт/код теперь реально
  применяется на форуме (включая все 116 тем Arizona).

### Попап — полноценное меню с вкладками (как в Arizona)

* Шапка (бренд + главный тумблер), **4 вкладки**:
  * **Темы** — поиск, фильтры категорий, «Случайная тема», сетка карточек
    (2 колонки, звёздочки избранного), «Показать ещё»;
  * **Настройка** — быстрые тумблеры (стекло/эффекты/фон), кнопки
    «Стиль Arizona» / «Сбросить вид» и все настройки группы «Оформление» +
    «Шрифты» (те же schema-driven контролы, что в полной панели);
  * **Твики** — все тумблеры и селекты группы «Элементы интерфейса»;
  * **Импорт/Экспорт** — экспорт JSON-файла, импорт файла, генерация/копирование
    и импорт share-кода, ссылки на разделы полной панели.
* Футер: активная тема (имя), индикатор статуса форума (клик — открыть
  форум), версия, кнопка полной панели.
* Вкладка «Настройка» включает группы **Оформление / Шрифты / Курсор** —
  все 7 настроек курсора (свой курсор, пресет, ссылка, цвет, размер,
  толщина) доступны прямо в попапе, с заголовками групп.
* Ширина 560 px, фиксированные шапка/вкладки/футер, прокручиваются только
  панели.
* `src/shared/lookPresets.ts` — пресеты «Стиль Arizona»/«Сбросить вид»
  вынесены в общий модуль (попап + дашборд), ключи приведены к точным
  dotted-путям.

### Техническое

* Попап переиспользует `renderGroupRows` (опции UI) — строка настройки в
  попапе и в панели это один и тот же рендерер с `sync()` на внешние
  изменения; строки строятся лениво при первом открытии вкладки.
* Импорт в попапе работает в режиме `replace` без модалок (нативный
  `confirm()` закрывает попап — модалки не используются).
* Счётчики: 114 настроек, 222 ключа i18n (RU=EN), 12 сьютов / 125 тестов.
* Версии: 1.3.0 (manifest, manifest.firefox, package.json).

## 1.1.0 (2026-10-11) — перенос фич Arizona Forum Styler

Реализация по исходникам Arizona Forum Styler v1.9.1 (найдены и изучены
пользователем), адаптированная под архитектуру Rodina Forum Styler
(TypeScript-модули, реестр селекторов, санитизация, тесты).

### Новые настройки (10 схемных + 2 массива)

* **Логотип форума** (`appearance.logoStyle`): градиент акцентов, анимированный
  градиент (маска из оригинального изображения) или своё изображение по URL;
  текстовые логотипы получают background-clip: text.
* **Обводка аватаров** (`appearance.avatarStyle`): акцентная обводка, свечение,
  покрас в цвет ника и свечение в цвет ника (цвет ника читается из DOM).
* **Синхронизация светлой/тёмной темы форума** (`appearance.syncForumMode`,
  по умолчанию выкл.): переключает стоковую вариацию XenForo под активную тему
  — кликом штатного тумблера или POST + перезагрузкой (меняет настройку
  аккаунта форума, поэтому opt-in).
* **Скрыть баннеры пользователей** (`tweaks.hideUserBanners`).
* **Скрыть переключатель темы форума** (`tweaks.hideStyleVariation`).
* **Убрать покрас ников** (`tweaks.removeUserPaints`) — сбрасывает
  пользовательские цвета ников к цветам темы.
* **Оформление заблокированных** (`tweaks.bannedStyle`): красный ник или
  значок рядом с ником (SVG-инжект, без внешних ассетов).
* **Анимированные аватары** (`tweaks.animatedAvatars`): подгружает исходные
  GIF из `/avatars/o/` вместо статичных превью, с восстановлением.
* **Кнопка «Ссылка» на выделение** (`tweaks.copySelectedLink`): копирует
  ссылку вида `#post-N:~:text=…` в тултипе цитаты.
* **Пункты меню форума**: панель в разделе «Интерфейс форума» — чекбоксы
  скрытия кнопок шапки (список собирается контент-скриптом) и CRUD своих
  ссылок в навигации (`tweaks.hiddenNavIds`, `tweaks.customNavItems` —
  валидируются и ограничиваются: 40 id / 10 ссылок).

### Улучшения

* **Анимации появления**: добавлено 8 стилей (опускание сверху, сдвиг
  влево/вправо, отдаление, поворот, флип по обеим осям, пружинистый подъём) —
  итого 13 стилей.
* Покрасы ников форума теперь видны по умолчанию (как на самом форуме);
  прежнее принудительное снятие включается тумблером «Убрать покрас ников».

### Техническое

* 5 новых модулей контент-скрипта: `userChrome`, `navbar`, `selectionLink`,
  `logo`, `variationSync`; логика наблюдения — MutationObserver + rAF-колла
  (без поллинга), активен только пока включена соответствующая фича.
* Новые селекторы в реестре: `logoImg`, `styleVariation`, `quoteTooltip`,
  `bannedUsername`.
* `shared/navButtons.ts` — общая модель кнопок навигации (контент-скрипт
  публикует, панель читает), `resolveNavId` покрыт тестами.
* Валидация: `hiddenNavIds`/`customNavItems` санитизируются при загрузке и
  импорте; сброс группы «Элементы интерфейса» сбрасывает и их.
* Счётчики: 100 настроек, 208 ключей i18n (RU=EN), 12 сьютов / 124 теста.
* Версии: 1.1.0 (manifest, manifest.firefox, package.json).

### Не переносилось (осознанно)

* Бейджи «экосистемы ArizonaAI» — привязаны к arizona-ai.ru, для Rodina
  неприменимы.
* Случайные настройки — закрываются существующей «Случайной темой».
* Стиль красного аватара бanned-пользователя — заменён более простым
  красным ником (атрибутная CSS-матрица Arizona не нужна).

## 1.0.0 (2026-10-02) — первый релиз

### Расширение

* MV3 для Chrome 110+ и Firefox 115+ (два манифеста, флаг сборки
  `--firefox`); разрешения — только `storage` + host-паттерн форума
  (+ необязательный `https://*/*` под удалённый AI-endpoint).
* Русский интерфейс; EN-словарь полон и симметричен (193/193 ключей,
  паритет плейсхолдеров проверяется тестами).
* Библиотека из **113 тем** в 8 категориях, фильтры, поиск, избранное,
  случайная тема, пользовательские темы (до 100).
* Редактор тем: 30 полей токенов, живой предпросмотр на форуме,
  undo/redo (50), дубликат, экспорт/импорт, проверка контраста.
* 90 настроек в 16 разделах: внешний вид, фон (цвет/градиент/картинка/
  GIF/видео/готовые сцены), эффекты, переходы, шрифты, курсоры (свой цвет
  или авто из цветов темы), стекло, интерфейс форума (9 тумблеров),
  производительность, доступность, AI, импорт/экспорт, экспериментальное,
  расширенное.
* Попап с мгновенным тумблером и быстрым выбором тем; онбординг при
  первом запуске; сброс раздела/всего с подтверждениями.
* Отладка: режим отладки, отчёт (версия, схема, статус селекторов и
  модулей, размер хранилища), аудит здоровья селекторов форума.
* Экспорт/импорт: JSON-бандл и share-код, режимы «объединить/заменить»,
  лимит 512 КБ, миграции, подробные ошибки; секреты не экспортируются.
* AI: локальная эвристика (честно подписана «без ИИ, офлайн») +
  опциональный OpenAI-совместимый endpoint с согласием, HTTPS и
  хранением ключа в отдельном ключе хранилища.

### Техническое

* Vanilla TypeScript (strict) + esbuild, без фреймворков и рантайм-зависимостей.
* Событийная live-sync через `chrome.storage.onChanged` (debounce 90 мс),
  без поллинга; кадровый цикл эффектов с FPS-cap и автопаузой скрытой вкладки.
* Инъекция стилей: `<style id="rfs-base">` + `<style id="rfs-vars">` +
  атрибуты `data-rfs-*` на `<html>` — переживает обновления DOM форума.
* Реестр селекторов XenForo с диагностикой здоровья; деградация
  намеренная (шаблоны конкретных страниц).
* Аудиты инструментов: `audit-i18n.mjs`, `audit-imports.mjs`.
* Тесты: 11 сьютов, **110 тестов** (`node:test` через esbuild).
* Ноль `innerHTML`/`eval` во всём исходнике; вся валидация —
  через санитизаторы `shared/validators.ts`.
