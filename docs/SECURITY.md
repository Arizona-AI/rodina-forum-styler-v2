# Безопасность и приватность

Резюме: расширение не собирает данные, не шлёт ничего в сеть по умолчанию и
работает с единственным host-паттерном. Любая сетевая активность возможна
только после явных действий пользователя.

## Разрешения

| Разрешение | Зачем |
| --- | --- |
| `storage` | настройки, темы, черновик, секреты |
| `content_scripts.matches: https://forum.rodina-rp.com/*` | единственная страница, где применяется стилизация |
| `optional_host_permissions: https://*/*` | **необязательное** — нужно только для удалённого AI-endpoint пользователя; запрашивается при включении удалённого провайдера |

Нет `tabs`, `webRequest`, `cookies`, `clipboardRead`, `downloads`,
`<all_urls>` и прочего. popup не использует `activeTab` — он работает
через хранилище, а не через вкладку.

## Сеть

* Единственный `fetch` во всём проекте — `ai/remote.ts`
  (`{endpoint}/chat/completions`), вызывается только при выполненном
  всех условиях (см. [AI.md](AI.md)): провайдер `openai`, явное согласие
  `ai.allowRemote`, HTTPS-endpoint, сохранённый ключ.
* Никакой телеметрии, аналитики, шаринга статистики. Google Fonts
  запрашивается только если пользователь выбрал шрифт оттуда
  (и отключается «разрешением шрифтов» в настройках).
* Таймаут запроса — 20 с; ответ обрабатывается через
  `extractJsonObject` + `sanitizeTokens`, в DOM попадают только
  проверенные цвета/длины.

## Секреты

* API-ключ живёт в отдельном ключе `rfs.aiSecrets` — не в `rfs.settings`.
* **Не экспортируется**: бандл экспорта и share-код собираются из
  settings/meta/customThemes/onboardingDone (проверено тестами и аудитом
  исходников — `aiSecrets` не упоминается в `storage/exportImport.ts`).
* **Не логируется**: логгер пишет только сообщения об ошибках
  (`save key failed: <ошибка storage>`), значение ключа не передаётся.
* **Не попадает в отчёт отладки**: отчёт содержит версию, схему, статусы
  селекторов/модулей и размер хранилища, а не его содержимое.
* Ключ можно удалить в любой момент полем ввода AI-раздела.

## Ввод и данные

* Никакого `innerHTML`/`insertAdjacentHTML`/`eval`/`new Function` во всём
  `src/` (проверяется греп-аудитом). DOM строится через
  `document.createElement`/`textContent`/`createElementNS`.
* Вся строка извне проходит санитизаторы `shared/validators.ts`:
  `sanitizeColor`, `sanitizeUrl` (только http(s) и `data:image`),
  `sanitizeGradient` (без `url()`, `var()`, `;`), `sanitizeFontFamily`,
  `sanitizeId`, `sanitizeText` (вырезает управляющие символы, режет по
  длине), `isPlainObject` — каждый со своим тестом.
* Импорт: лимит файла 512 КБ, JSON-парсинг с проверкой схемы бандла,
  миграции по версиям, коэрция каждой настройки по `SETTINGS_SCHEMA`
  (клампы, типы, белый-список), санитизация каждой темы, лимит 100 тем.
  Ошибки возвращаются списком и показываются пользователю, молчаливых
  частичных применений нет.
* Токены тем компилируются повторно в `compileThemeVariables`: даже
  вручную подредактированный JSON не может внавес ничего, кроме цветов
  и длин — инъекция CSS через значения невозможна.

## Контент-скрипт

* Инъекция — два `<style>` и атрибуты на `<html>`; на форуме нет
  Content-Security-Policy (проверено при исследовании), поэтому стили
  применяются штатно; sanitize-слой всё равно работает на входе.
* Скрипт ничего не читает из страницы, кроме структуры DOM для
  применения стилей, и никуда это не отправляет (сеть из контент-скрипта
  отсутствует полностью).
* `all_frames: false` — только верхний фрейм.

## Резервирование

* Экспорт содержит только то, что пользователь создаёт сам: настройки и
  темы. Ключи, метаданные браузера и личные данные — никогда.

## Известные ограничения

* Share-код — это base64 от JSON, а **не** шифрование: treat его как
  обычный текст настроек. Секретов в нём нет, но персональные названия
  своих тем прочитает любой, у кого код есть.
* `optional_host_permissions: https://*/*` — широкая необязательная
  грамматика нужна под произвольный endpoint пользователя; запрашивается
  только при включении удалённого AI и её можно не выдавать.
* Стилизация применяется только к `forum.rodina-rp.com`; расширение не
  пытается работать на других сайтах и не имеет для этого разрешений.
